Especificación de Requisitos: Aplicación de Cálculo y Proyección de Pobreza
Objetivo General Desarrollar una aplicación orientada a calcular el nivel de pobreza de personas y grupos a partir de diversas variables socioeconómicas. El sistema debe permitir el análisis en momentos específicos o a través de distintos periodos de tiempo, calcular tendencias, generar pronósticos a futuro y recomendar políticas de mitigación.
Módulo de Ingreso de Datos y Variables
La aplicación debe aceptar datos ingresados directamente por el usuario a través de un cuestionario integrado.
Debe permitir la importación de datos masivos provenientes de estudios oficiales, como la encuesta de ingreso-gasto de los hogares.
El cálculo debe contemplar variables multidimensionales que van desde el nivel de ingresos hasta las condiciones físicas de la vivienda.
El sistema debe ser capaz de segmentar la información para medir la pobreza a nivel general, pobreza femenina o pobreza masculina dentro de un hogar.
Módulo de Cálculo y Clasificación (Índice de Pobreza)
El motor de la aplicación debe procesar los datos para emitir un índice de pobreza, con una simplicidad de uso comparable a una calculadora de Índice de Masa Corporal (IMC).
El resultado no debe ser binario (pobre/no pobre), sino que debe clasificar a los usuarios en distintos niveles progresivos (por ejemplo, desde pobreza muy baja hasta pobreza muy alta) basados en proporciones de ingreso y gasto.
La interfaz debe proporcionar una explicación clara sobre lo que significa e implica cada nivel de pobreza calculado.
Módulo de Análisis Temporal y Pronósticos
El sistema debe permitir el análisis dinámico mediante la evaluación de datos correspondientes a varios años.
Debe calcular y visualizar la tendencia histórica de la pobreza para el individuo o grupo evaluado, mostrando si la situación ha mejorado o empeorado.
Con base en el histórico de datos, la aplicación debe generar un pronóstico que detalle la perspectiva futura a la que se enfrenta el sujeto de estudio.
Módulo de Recomendaciones y Política Pública
A partir del nivel de pobreza obtenido, el sistema debe emitir recomendaciones específicas de política pública orientadas a mitigar y disminuir dicha condición.
Las recomendaciones generadas por la aplicación funcionarán como un marco técnico ideal sobre las acciones necesarias, independientemente de si existe o no voluntad política para su implementación real.
Usuarios Objetivo
El sistema debe estar diseñado para ser utilizado tanto por individuos que deseen conocer su estatus personal, como por investigadores e instituciones que requieran comparar y analizar la evolución de la pobreza en distintos periodos de tiempo.
